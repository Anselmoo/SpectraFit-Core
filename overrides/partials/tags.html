Its shipped partial branches on `tag.url`, which is therefore always empty, so every chip took the `{% else %}` arm and rendered ``. Measured on the live site: 47 tagged pages, 12 distinct tags, zero clickable, and the tag data also sits in 768 of the 817 search records while the page config hands the search UI `"tags": null`. No key in zensical.toml changes that. This override supplies the missing half by pointing each chip at `docs/tags.md`, generated by `docs/_render_tags.py` from the same front-matter the chips come from. SLUG CONTRACT: the anchor built here — lowercase, spaces to hyphens — must match `_render_tags.py::slug`. That function uses a regex over any non-alphanumeric run, which is a superset of this filter chain, and it FAILS THE BUILD if a tag would slug differently under the two rules.
