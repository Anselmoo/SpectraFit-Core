## Solver behavior

Solver-choice demonstrations — the same spectrafit-core solvers from a
different angle, where the "right" answer depends on what the data or the
constraints actually look like, not just which solver runs fastest.

## Advanced

An external, independently-implemented cross-check: [lmfit](https://lmfit.github.io/lmfit-py/)
as an oracle, not just spectrafit-core's own alternate solvers — the same
idea the project's own benchmark harness runs at scale, distilled into one
readable script.

<div class="grid cards" markdown>
