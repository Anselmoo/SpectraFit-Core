# Superseded renderings

`fig_constraint_grid-3row-2026-08-18.{png,pdf}` is the three-row version of
Figure 3: scenarios A, B and C only.

It was replaced on 2026-08-18 because the manuscript's verdict is the
C-versus-D comparison and D was never drawn, so the argument asked the reader to
take the picture on trust. `fig_constraint_grid.py` now draws D as a fourth row,
labelled as one joint fit shown in two panels.

Kept rather than deleted: the three-row grid is still the cleaner object when
the point being made is only about the per-spectrum hypotheses, and it is what
every earlier draft of the paper referred to.
